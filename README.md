# 迭代法 OPC 模型（Hopkins 前向 + 边缘/角落移动）

一个自研的**迭代法光学邻近效应修正（OPC）**教学/科研演示模型：

- **输入**：像素化版图（内置 6 种参数化示例图形，或从 `.txt`/`.png` 读取自定义 0/1 矩阵）
- **前向模型**：Hopkins 部分相干成像模型，用 numpy 数值实现（Abbe 光源点采样法，与 Hopkins 方程数学上严格等价），固定阈值光刻胶模型
- **修正方式**：经典边缘基 OPC——边缘分段按 EPE 反馈移动（带阻尼、限幅、防振荡），凸角自动生长 serif、凹角自动加深 hammerhead（统一 45° 切口反馈，无需单独代码路径），辅以像素级清理（去孤立岛/填小洞）
- **流程**：目标图形 → 光栅化初始掩模 → 前向仿真（空间像 → 阈值印刷轮廓）→ 计算 EPE → 移动边缘/角落 → 重新光栅化 → 迭代，直至收敛或达到最大迭代次数

| `line_end_array` | 3 条周期线，中间线线端回缩 | 线端在周期环境中的修正 |

**入门顺序建议**：`elbow_array`（周期+角点）→ `dense_lines`（纯边缘）→ `contact_array`（二维周期）→ `line_end_array`（线端）。

**自定义版图**：`DEMO_NAME='custom'` 时读取 `CUSTOM_MASK_FILE`：
- `.txt`：`GRID_N × GRID_N` 的 0/1 矩阵（空格/逗号分隔均可，1=图形）
- `.png`：灰度图，像素值 ≥128 记为图形

## 算法原理（物理背景）

**前向模型（Hopkins 部分相干成像）**。投影光刻的像强由 Hopkins 方程描述：

    I(x) = ∫∫ TCC(f', f'') · M(f') · M*(f'') · exp(j·2π·(f'−f'')·x) df' df''

其中 M(f) 为掩模透射谱，交叉传递系数 TCC(f',f'') = ∫ S(f)·P(f+f')·P*(f+f'') df 由光源强度分布 S（环形照明 σ∈[0.6,0.9]）与光瞳函数 P（|ν|≤1，即 |f|≤NA/λ）决定。数值实现采用**光源点采样法（Abbe 法）**：把光源离散成环上均匀分布的采样点 {f_s, w_s}（±f_s 严格成对，保证对称图形得到对称像），每个点对应一束倾斜平面波，其像场 E_s(x) = FT⁻¹[M(f)·P(f+f_s)]，总像强 I = Σ_s w_s|E_s|²。空间像按**开域强度归一化**（空掩模 → I=1），光刻胶为固定阈值模型：I < 0.3 处形成图形（暗）。掩模像素化是可行的，因为掩模锯齿是亚分辨率高频、被光瞳低通截断（带宽 |f| ≤ (1+σ_out)·NA/λ ≈ 0.013 nm⁻¹，远小于像素网格奈奎斯特频率 0.25 nm⁻¹）。

**边界条件：周期边界（默认）**。掩模版图被视为**无限周期阵列的一个周期**（`config.BOUNDARY_MODE='periodic'`）。FFT 的循环卷积天然实现这一点：视场边界与对面的边界无缝相接，跨度越界的图形会自动环绕到对面（`mask_ops.polygons_to_pixels(..., wrap=True)`），光刻胶扩散也按 `wrap` 处理。对周期掩模这不是近似——周期谱只含离散谐波 f_k = k/(N·dx)，光瞳只需在这些谐波上取值，因此 DFT 实现是**精确**的；中心差分采样的"圆形光瞳看起来只有 5 个频点宽"也不算误差。

`--selftest` 的第 6 项专门验证这一点：把掩模在视场内循环平移，空间像必须精确跟着平移（实测误差 ~1e-15）；跨越视场边界的图形，其上、下边缘的像必须连续。

若确实要模拟孤立图形（不与对面周期串扰），把 `BOUNDARY_MODE` 改为 `'isolated'`：掩模零填充到 2N 后计算再裁中心（线性卷积），视场外按清晰场处理，FFT 时间约 4 倍。

**EPE 与反馈**。边缘放置误差（Edge Placement Error）定义为印刷轮廓与目标边界的带符号距离（沿掩模边外法向，正 = 印大）。每条掩模边沿法线采样空间像、双线性插值找阈值交点得到 EPE；反馈公式：

    Δ = −η·EPE → 一阶惯性阻尼 → 限幅 min(3nm, 2·|EPE|)

限幅 2·|EPE| 保证印刷增益 ≥ 0.5 时不翻号（防极限环振荡）；累计偏置上限 40nm 模拟掩模规则约束（角落区域印刷轮廓跟不上掩模偏置，不设上限掩模会无益外扩）。

**角落修正的统一方块结构**。角点被替换成经典的 OPC 结构：凸角**外扩方块 serif**（沿两条邻边连通地外扩一个 s×s 方块）、凹角**方形缺口 hammerhead**（挖去一个 s×s 方块）。两个结构由同一对切口段（共享方块边长 s）与普通边走完全相同的 EPE 反馈：设印刷轮廓沿角平分线相对目标角点偏移 t（圆化量），则切口段 EPE = t ± s（凸角 +s、凹角 −s），反馈不动点 s* = |t| ——serif/hammerhead 自动长到恰好补偿角点圆化量，凸角/凹角公式完全一致，无需单独的角落反馈代码。

## 预期结果

默认参数（λ=193nm, NA=1.35, 环形 0.6~0.9, 阈值 0.3, 2nm 像素, GRID_N=448,
线宽 120nm, 阻尼 0.85）下各示例的**印刷轮廓对称平均偏差**（初始 → 输出）：

| 示例 | 初始 | OPC 后 |
|---|---|---|
| elbow_array | 11.0 nm | 1.7 nm |
| dense_lines | 13.5 nm | 1.4 nm |
| line_end_array | 13.6 nm | 1.4 nm |
| contact_array | 11.7 nm | 1.7 nm |
| l_shape | 10.3 nm | 1.8 nm |
| t_shape | 10.0 nm | 1.9 nm |
| line_end_gap | 14.9 nm | 1.7 nm |
| isolated_line | 13.6 nm | 1.1 nm |

掩模形态符合经典 OPC 规范：边缘偏置约 ±15nm（上限 `MAX_BIAS_NM=25`），
凸角外扩**方块 serif**（肘形阵列约 18nm），凹角**方形缺口 hammerhead**，
掩模面积约为目标的 1.1 倍。

**历史最佳状态判据**：迭代中角点区可能出现过冲振荡，程序记录每轮的
"印刷轮廓与目标的对称平均偏差"，输出偏差最小的一轮（而不是末轮），
因此运行日志里的 RMS EPE 可能略有起伏而输出仍是最佳状态。

## 已知局限（物理原因）

1. **角点修正有极限**：凸角圆化 ~30nm 需 serif + 边缘偏置协同补偿；凹角 hammerhead 受短邻边长度约束（s ≤ 邻边/2）。更小的图形（如 45nm 孤立线）可能初始就印不出来——这是分辨率极限，也是逆光刻技术（ILT）的动机。
2. **残差不低于像素尺寸**：2nm 网格下 EPE 的物理极限约 ±1px，`EPE_TOL_NM` 不应设得比像素尺寸小。
3. **自定义输入应为干净图形**：像素提取只对轴对齐、无锯齿的目标可靠（不要把 OPC 输出掩模再当输入）。
4. 掩模多边形为浮点状态、像素为派生视图：亚像素位移累积在浮点几何里，不因光栅化丢失精度。
